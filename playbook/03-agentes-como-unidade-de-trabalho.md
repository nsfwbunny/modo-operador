# Capítulo 3 — Agentes como unidade de trabalho

## Objetivo
Explicar o que é um agente de IA na prática e como usá-lo como unidade de execução, não como assistente.

## Tópicos internos

- Tipos de agentes disponíveis hoje (Jules, Antigravity, Gemini, Claude)
- Como dar uma tarefa real para um agente sem perder controle
- Gates de aprovação: quando deixar o agente rodar sozinho
- Exemplo real: tarefa executada por agente com PR aberto
