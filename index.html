Bônus 01
Prompt Library

Servidor MCP funcional em TypeScript com 5 tools pré-configuradas: filesystem, sqlite, fetch, exec e notify. Inclui config pronta para Claude Desktop e README de instalação. Roda com npm install && npm run build.

3 workflows exportáveis em JSON: Content Pipeline (geração diária), Code Review Assistant (análise automática de PRs) e Document Processor (OCR + extração estruturada com LLM local). Importa no Antigravity, configura env vars, executa.

Operador's Daily Stack
