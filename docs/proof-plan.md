# Proof Plan — Modo Operador

## Objetivo

Antes de abrir a oferta, publicar prova real de pelo menos 2 casos.

## Cases planejados

| Case | Sistema | Evidência necessária | Status |
|---|---|---|---|
| JARVAS | Agente autônomo Python + Jules | Repo público + demo | PENDENTE |
| Jules → GitHub | Build via agente sem código manual | PR real publicado | PENDENTE |
| MCP stack | Antigravity + MCP + Perplexity | Fluxo documentado | PENDENTE |
| Media engine | Conteúdo gerado + distribuído por agente | Post real publicado | PENDENTE |

## Critério de aprovação

Um case só está pronto quando:
1. O sistema existe e funciona.
2. A evidência é pública (repo, post, vídeo ou print verificável).
3. O arquivo em `proofs/cases/` está preenchido sem PENDENTE.
